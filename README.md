# Kizme

Kizme es una propuesta digital para conocer personas y abrir nuevas oportunidades de conexión. La idea central es crear un espacio moderno, cercano y fácil de usar para que las personas puedan descubrir otras personas con intereses similares, conversar desde el primer contacto y construir relaciones auténticas.

Esta web está en desarrollo y está pensada para publicarse de forma sencilla en GitHub Pages como una landing page inicial. Su objetivo es presentar la propuesta de manera clara, atractiva y profesional antes de ampliar sus funciones.
